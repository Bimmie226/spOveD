# Ghi chú tài liệu về quá trình tự nghiên cứu và thực hành các kiến thức trong DevOps 

## Danh sách dự án lab 

| STT | Name Project       | Framework                      |
| --- | ------------------ | ------------------------------ |
| 1   | todolist           | Frontend - vue                 |
| 2   | visionui           | Frontend - react               |
| 3   | shoeshop-ecommerce | Backend - springboot + MySQL   |

## Triển khai dự án
1. Dự án nào thì có công cụ tương ứng

2. Chỉ cần lưu ý duy nhất là file cấu hình trong dự án

3. Triển khai dự án cần đúng 2 bước 1 là build và 2 là run

**NOTE:**

- Mỗi dự án sẽ có thư mục riêng
- Mỗi dự án sẽ có user riêng

## Triển khai dự án backend

1. Cài đặt công cụ cần thiết => công cụ

2. Xem và sửa file cấu hình => file cấu hình

3. Cài đặt và thiết lập database => công cụ

4. Build dự án => build

5. Run dự án => run

6. Kiểm tra hoạt động => check
