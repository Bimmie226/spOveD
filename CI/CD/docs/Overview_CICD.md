# CI/CD
## CI/CD là gì?
CI/CD được chia thành 2 bước: 
- CI(Continuous Integration): clone code, build dự án, tích hợp các công cụ test để đảm bảo chất lượng source code
- CD(Continuous Deployment/Delivery):
  - Deployment: triển khai hoàn toàn tự động (dev commit -> chức năng mới triển khai)
  - Delivery: triển khai thủ công 

## Công cụ triển khai
- Gitlab CI/CD
- Jenkins
